# Keyboard Effects

A lightweight Windows desktop application that adds keyboard sounds and animated visual effects to your desktop.

Keyboard Effects runs in the background and provides a modern system tray interface where individual effects can be enabled or disabled at any time.

The project is completely open source. You can run the Python source code directly or build your own standalone Windows executable.

---

## ✨ Features

### ⌨️ Keyboard Sounds
Plays a sound whenever a keyboard key is pressed.

Special sounds can be assigned to keys such as:

- Enter
- Space
- Regular keyboard keys

The sound files can be replaced with your own audio files.

---

### ✨ Cursor Trail

Creates small particles that follow your mouse cursor.

The effect can be enabled or disabled independently from the other effects.

---

### 💗 Cursor Glow

Adds a soft pink glow around the mouse cursor.

The glow is animated and designed to remain subtle while still being visible.

---

### 🪟 Active Window Glow

Highlights the currently active application window with a pink outline.

The application automatically detects the active window and draws the effect around it.

Windows such as the desktop and taskbar are ignored.

---

### 🌧️ Rain Effect

Displays animated rain particles across the desktop.

The rain effect runs independently and can be disabled from the settings window.

---
